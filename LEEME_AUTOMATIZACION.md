# Paquete completo

Este ZIP sustituye al paquete parcial anterior. Incluye config.yaml, run.sh,
Dockerfile, repository.yaml, scripts, workflow, traducciones y documentacion.

Las instrucciones actualizadas estan en README.md. Para migrar una app local,
lee MIGRACION.md. No se incluyen contrasenas ni una IP de usuario.
Zona horaria predeterminada: Europe/Madrid.

Los PNG oficiales se descargan durante la primera publicacion en GitHub.
No se incluyen como archivos binarios dentro de este ZIP.
