# Kimai para Home Assistant OS

App comunitaria para registro de tiempos, clientes y proyectos.

Usa la imagen oficial de Kimai adaptada a las opciones y al almacenamiento
persistente de Home Assistant, con MariaDB externa a esta app.

Zona horaria predeterminada: **Europe/Madrid**. No contiene una IP de instalacion
ni credenciales personales. La configuracion del acceso y de la base de datos se
introduce en la pestana Configuracion de la app.

Consulta DOCS.md antes de iniciar una instalacion nueva o migrar una app local.
